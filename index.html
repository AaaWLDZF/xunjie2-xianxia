❓ API 接入教程

三步接入（以 DeepSeek 为例，约 3 分钟）

  1. 注册并充值：打开 DeepSeek 开放平台，注册 / 登录，先充 10 元即可畅玩数千轮；
    https://platform.deepseek.com
  2. 创建密钥：进入 API keys 页面 →「创建 API key」→ 复制 sk- 开头的密钥（只完整显示一次）；
    https://platform.deepseek.com/api_keys
  3. 回到本页填写三项，然后点「💾 保存并连接」并勾选「启用 AI」：
    API 地址：https://api.deepseek.com/v1/chat/completions
    API Key：粘贴你刚创建的 sk- 密钥
    模型名：deepseek-v4-pro
    更便宜可填：deepseek-flash

费用参考

每轮对话约消耗 4~5K tokens：deepseek-v4-pro 约 ¥0.01~0.05 / 轮（闲时更低），deepseek-flash 约 ¥0.003~0.01 / 轮；10 元余额通常可支撑 2000~8000 轮，实际以平台账单为准。

常见问题

  1. 401 密钥无效：密钥复制不全或已被删除，回密钥页重新创建并完整复制；
  2. 连接超时：检查网络是否可达服务商，地址是否以 /v1/chat/completions 结尾；
  3. CORS 跨域报错：该服务商不允许浏览器直接调用，请换用 DeepSeek 或支持 CORS 的服务商；
  4. 隐私：Key 只保存在你自己的浏览器本地（localStorage），本游戏为纯静态页面、无后端、不上传任何数据；
  5. 其他服务商：兼容所有 OpenAI 兼容接口（硅基流动 / Moonshot / 通义等），把地址换成对应的 /v1/chat/completions、模型名对应替换即可。
